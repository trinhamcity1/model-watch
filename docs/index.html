How this works

  • Every model gets the same fixed prompts, a fresh chat for each, temperature 0, thinking off, and the same system prompt.
  • Scores come from automatic checks and hand-made gold labels, not from another model grading answers.
  • A difference counts only above a set margin (0.05 F1, 2 labels, 1 answer, 10% for speed). Smaller gaps show as "too close".
  • Test data is invented: a made-up gene (EPLX2), a made-up report and eight made-up parent statements. No UTA data is used.
  • Speeds come from a laptop CPU. They rank models against each other and do not predict A100 speed.
  • Sample size is small (16 gold labels, 10 report and safety questions), so one run can swing by a few points.

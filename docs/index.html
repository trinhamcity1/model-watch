How this works

  • RAG-HPO asks the language model to pull phenotype phrases out of each document, then matches them to Human Phenotype Ontology terms with a fixed search index. Only the language model changes between rows.
  • Scoring is per document: the set of HPO codes returned (category Abnormal) against the expert codes. Precision, recall and F1 are summed over all documents; "per doc" is the average of each document's F1.
  • Negation errors count codes the experts marked as absent (for example "no seizures") that the model reported as present. Only ID-68 marks these.
  • The same documents are used every run: all 68 ID-68 notes and a fixed sample of 60 GSC+ abstracts. A small control model is re-run each time to catch changes in the environment.
  • "Worth a server test" means the model beats the best selected baseline by at least 0.03 F1 on every dataset it was tested on, with no more negation errors. It is a prompt to look closer, not a decision to switch.
  • Scores are document-level, so they compare with document-level results in the literature (for example PhenoTagger), not mention-level ones.

How this works

  • Every model gets the same fixed prompts, a fresh chat for each, temperature 0, the same system prompt, and thinking off where the model allows it. Models that cannot switch thinking off (gpt-oss) get a larger answer limit so they are not cut off.
  • Scores come from automatic checks and hand-made gold labels, not from another model grading answers.
  • The verdict is based on quality measures; speed is shown alongside. A difference counts only above a set margin (0.05 F1, 2 labels, 1 answer, 10% for speed). Smaller gaps show as "too close".
  • Test data is invented: a made-up gene (EPLX2), a made-up report and eight made-up parent statements. No real patient or institutional data is used.
  • Speeds come from a free Kaggle GPU (two T4 cards). They rank models against each other and do not predict A100 speed.
  • Sample size is small (16 gold labels, 10 report and safety questions), so one run can swing by a few points.
Results come from models.json. Models without results are added after a run.
